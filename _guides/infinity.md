# Infinity Theme Guide

Infinity is a responsive, single column Tumblr theme inspired by the look and feel of Twitter. Features a search bar, updates tab and easily customisable colours, fonts & sizes.

* **Sidebar:** Optional updates section, up to 5 custom links & icons and as many Tumblr page links as you want
* **Header:** Optional header and avatar images, editable bio info
* **Colours:** All colours are independently editable via Tumblr’s customisation menu or select from prebuilt colour schemes
* **Fonts:** Separate header and body fonts using Google Fonts
* **Sizes:** Custom post, sidebar, font, padding, margin, avatar, and corner rounding sizes editable via Tumblr’s customisation menu
* Fully supports NPF & legacy posts

## Advanced Theme Customisation

### Sidebar

5 custom links with ability to choose an icon from a drop down menu in Tumblr’s Customisation Menu.

> Home, Ask, Submit, Archive & Tumblr page links do not have a custom icon selection, refer to [Google’s Material Symbols](/) documentation for a comprehensive list of available icons.if you want to change the icons.
{: .notice}

Updates section will be hidden automatically if the text box is left empty in Tumblr’s Customisation Menu, the title is optional and ***will not*** hide the updates section if left empty.

The sidebar is mobile responsive and will resize or otherwise change format to fit the screen. Some content, such as the updates section, will not be visible.

### Header

Leaving any images or fields empty will automatically hide the element.

The avatar image has a background accent colour for transparent images and an option for a smaller size.

**Profile bio info:** Category/Account type, Location, Bio Link, Birthdate, and Account Creation Date (automatically generated, toggleable).

### Colours

**Colour Scheme:** Tumblr Blue, Twitter Light, Twitter Dim, Twitter Dark, or Custom to select your own colours using Tumblr’s Customisation Menu.

**Customisable colours include:** Background Colour, Post/Header Background Colour, Post/Header Text Colour, Sidebar Text Colour, Post/Header Borders Colour & Accent Colour (some colours will be automatically generated based on these colour selections for ease of customisability).

### Other Options

Option to upload a custom favicon image in the Tumblr Customisation Menu.

**Customisable sizes include:** Post/Header Width, Sidebar Width, Font Size, Margins (space between posts/sidebar/header), Padding (space within posts/sidebar/header) & Corner Rounding.
